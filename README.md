# Coach 365

แอปมือถือ (PWA) สำหรับแผนเปลี่ยนตัวเอง 1 ปี (28 ก.ย. 2569 – 27 ก.ย. 2570)

- **วันนี้:** เป้าก้าว หน้าต่าง IF และท่าออกกำลังกายของวันนั้น พร้อมบันทึกน้ำหนัก รอบเอว ก้าว ค่ากิน และเช็กลิสต์
- **เวท:** โปรแกรมตามเฟส (Full body A/B → Upper/Lower) ภาพท่าเคลื่อนไหว 12 ท่า (บาร์เบล ดัมเบล ตัวเปล่า) บันทึกน้ำหนักที่ยกและดูสถิติครั้งก่อน
- **เงิน:** ติดตามเป้าเงินเก็บ 100,000 บาท รายได้งานเสริม และ passive income เทียบเป้า 300 บาท/วัน
- **สถิติ:** กราฟน้ำหนักเทียบเส้นเป้า 100 → 78 กก. และบันทึกย้อนหลัง
- **เตือน:** แจ้งเตือนตามตาราง และส่งออกเป็นไฟล์ปฏิทิน (.ics)

ไม่มี build step ไม่มี dependency เป็น HTML/CSS/JS ล้วน ข้อมูลเก็บใน `localStorage` ของเครื่อง

## ขึ้น GitHub Pages

1. สร้าง repo ใหม่บน GitHub เช่น `coach365` (Public หรือ Private ก็ได้ แต่ Pages ฟรีต้องเป็น Public)
2. อัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้น repo
   ```bash
   git remote add origin https://github.com/<username>/coach365.git
   git push -u origin main
   ```
3. ไปที่ **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`** แล้วกด Save
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<username>.github.io/coach365/`

## ติดตั้งลงมือถือ

- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "ติดตั้งแอป"
- **iPhone (Safari):** ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" (ต้องติดตั้งก่อนถึงจะเปิดแจ้งเตือนได้ และต้องเป็น iOS 16.4 ขึ้นไป)

## เรื่องแจ้งเตือน

เว็บแอปยังตั้งเวลาแจ้งเตือนล่วงหน้าตอนปิดแอปไม่ได้ (เบราว์เซอร์ยังไม่รองรับ) จึงมี 2 ชั้น:

1. **ในแอป:** กด "เปิดการแจ้งเตือน" แอปจะเตือนตามเวลาขณะที่แอปเปิดอยู่หรือค้างอยู่เบื้องหลัง
2. **ปฏิทิน (แนะนำ):** แท็บ "เตือน" → "ดาวน์โหลดปฏิทินแจ้งเตือน (.ics)" แล้วเปิดไฟล์ด้วยปฏิทินในมือถือ มือถือจะเตือนตรงเวลาทุกวันแม้ไม่ได้เปิดแอป
   - ถ้านำเข้า Google Calendar: ควรสร้างปฏิทินใหม่ชื่อ "Coach 365" แล้วตั้งการแจ้งเตือนเริ่มต้นเป็น "ตอนเริ่มกิจกรรม" เพราะ Google ไม่อ่านการแจ้งเตือนจากไฟล์ .ics

ถ้าต้องการแจ้งเตือนแบบแอป native จริง ภายหลังสามารถห่อด้วย [Capacitor](https://capacitorjs.com/) + Local Notifications plugin แล้วสร้างไฟล์ APK ได้

## สำรองข้อมูล

ข้อมูลอยู่ในเครื่องเดียว ส่งออกไฟล์ JSON ทุกเดือนที่แท็บ "เตือน" → "สำรองข้อมูล" และนำเข้ากลับได้เมื่อเปลี่ยนเครื่อง

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าจอ 5 แท็บ |
| `app.js` | ตรรกะแผน บันทึก เงิน สถิติ แจ้งเตือน |
| `exercises.js` | คลังท่า โปรแกรมตามเฟส และตัววาดภาพท่าแบบเคลื่อนไหว |
| `style.css` | ธีมสว่าง/มืดตามเครื่อง |
| `sw.js` | ใช้งานออฟไลน์ + กดแจ้งเตือนแล้วเปิดแอป |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งเป็นแอป |
