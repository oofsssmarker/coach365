# Coach 365

แอปมือถือ (PWA) สำหรับแผนเปลี่ยนตัวเอง 1 ปี เริ่มวันที่ 1 = จันทร์ 28 ก.ย. 2569

- **วันนี้:** เป้าก้าว หน้าต่าง IF ตารางวันนี้ (มีเวลาพักผ่อนรวม 3 ชม.) ตัวจับเวลานั่งสมาธิพร้อมจังหวะหายใจ บันทึกน้ำหนัก/รอบเอว/เช็กลิสต์ และกราฟน้ำหนักเทียบเป้า 100 → 78 กก.
- **อาหาร:** ถ่ายรูปอาหาร + AI ประเมินแคลอรี่ (ใช้ API key ของคุณเอง) หรือเลือกเมนูร้าน/ชั่งวัตถุดิบเอง แผนอาหาร 7 วัน 2 ชุดสลับสัปดาห์ สูตรอาหาร 20 สูตรพร้อมปริมาณเป็นกรัม วิธีสั่งอาหารนอกบ้าน และรายการซื้อของ
- **เวท:** โปรแกรมตามเฟส (Full body A/B → Upper/Lower) รูปท่าจริง 18 ท่า บันทึกน้ำหนักที่ยก และ **ตรวจท่าด้วยกล้อง** (นับครั้ง วัดมุมข้อต่อ บอกจุดผิดเป็นเสียงภาษาไทย) + ตรวจบุคลิกท่ายืน (คอยื่น ไหล่ห่อ)
- **เงิน:** เป้าเงินเก็บ 100,000 บาท รายได้งานเสริม และ passive income เทียบเป้า 300 บาท/วัน
- **ตั้งค่า:** แจ้งเตือน 15 รายการ + ส่งออกเป็นไฟล์ปฏิทิน (.ics) ตั้ง AI และสำรองข้อมูล

ไม่มี build step เป็น HTML/CSS/JS ล้วน ข้อมูลเก็บในเครื่อง (`localStorage` + รูปอาหารใน IndexedDB)

## ความแม่นยำ (อ่านก่อนใช้)

- **แคลอรี่จากรูป:** ไม่มีระบบไหนแม่น 100% เพราะรูปมองไม่เห็นน้ำมัน น้ำตาล และน้ำหนักจริง AI มักคลาดเคลื่อน ±20–30% แอปจึงให้ช่วงต่ำสุด–สูงสุด และให้แก้ตัวเลขเองได้ ถ้าต้องการแม่นที่สุด ให้ใช้ตาชั่งดิจิทัลกับโหมด "ชั่งวัตถุดิบเอง" (คลาดเคลื่อนประมาณ ±5–10%) หรืออ่านค่าจากฉลาก
- **ตรวจท่า:** AI วัดมุมข้อต่อจากกล้อง 2 มิติ วางกล้องด้านข้าง สูงระดับเอว ห่าง 2–3 เมตร ใช้เป็นตัวช่วย ไม่แทนโค้ชจริง

## ขึ้น GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save
แอปจะอยู่ที่ `https://<username>.github.io/coach365/` (กล้องต้องใช้ https ซึ่ง GitHub Pages รองรับ)

## ติดตั้งลงมือถือ

- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "ติดตั้งแอป"
- **iPhone (Safari):** ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" (iOS 16.4+ สำหรับแจ้งเตือน)

## แจ้งเตือน

เว็บแอปตั้งเวลาแจ้งเตือนล่วงหน้าตอนปิดแอปไม่ได้ จึงมี 2 ชั้น:
1. **ในแอป:** เตือนตามเวลาขณะที่แอปเปิดหรือค้างอยู่เบื้องหลัง
2. **ปฏิทิน (แนะนำ):** แท็บตั้งค่า → ดาวน์โหลด .ics → เปิดด้วยปฏิทินมือถือ ถ้าใช้ Google Calendar ให้ตั้งการแจ้งเตือนเริ่มต้นของปฏิทินเป็น "ตอนเริ่มกิจกรรม"

## AI ประเมินอาหาร

สร้าง API key ที่ https://console.anthropic.com (ต้องเติมเครดิต) แล้ววางในแท็บตั้งค่า key เก็บในเครื่องเท่านั้นและไม่รวมในไฟล์สำรอง แอปเรียก Claude API จากเบราว์เซอร์โดยตรงด้วย `@anthropic-ai/sdk`

## เครดิต

- รูปท่าออกกำลังกาย: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense / สาธารณสมบัติ)
- ตรวจท่า: [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) (Apache-2.0) ประมวลผลในเครื่อง ไม่ส่งวิดีโอออกไป

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` / `style.css` | หน้าจอ 5 แท็บ ธีมสว่าง/มืดตามเครื่อง |
| `app.js` | แผน บันทึก สมาธิ ตาราง เงิน สถิติ แจ้งเตือน |
| `food.js` / `meals.js` | บันทึกอาหาร AI ประเมินรูป สูตร แผนอาหาร |
| `exercises.js` / `img/` | คลังท่า โปรแกรมตามเฟส รูปท่า |
| `posecheck.js` | ตรวจท่าด้วยกล้อง |
| `sw.js` / `manifest.webmanifest` | ใช้งานออฟไลน์ ติดตั้งเป็นแอป |
